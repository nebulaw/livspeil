# Specs

Design specs for Livspeil. During planning these live in the Livspeil Claude Project and are exported here as they stabilize:

- `livspeil-vision-and-decisions.md` (hub: thesis, decisions, roadmap)
- `livspeil-kernel-spec-v0.md` (Phase 0 kernel; this repo implements it)
- `livkit-spec-v0.md` (Livkit UI toolkit, Phase 1)
- `repo-conventions-and-licensing.md`

Once copied, each spec is the source of truth for its milestone; update it in the same pull request as the code that changes the design.
